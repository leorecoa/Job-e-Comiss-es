# Frontend Rules

- Preserve the current glassmorphism identity, brand mark, splash screen and polished controls.
- `/book` and `/agendar` must remain public.
- The internal panel must stay protected when Supabase Auth is configured.
- Add loading, empty and error states for async flows.
- Keep forms responsive and avoid text overflow on mobile.
- Do not add landing pages where a usable screen is expected.
- Use existing components and lucide icons before introducing new UI patterns.
