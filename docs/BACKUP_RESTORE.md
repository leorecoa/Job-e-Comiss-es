# Backup e Restauracao

O Job e Comissoes salva os dados no navegador usando `localStorage`. Por isso, backups regulares sao importantes.

## Quando fazer backup

- Antes de limpar dados do navegador.
- Antes de trocar de computador ou celular.
- Antes de restaurar um backup antigo.
- Ao final de um periodo financeiro importante.

## Como baixar backup

1. Abra o app.
2. Acesse `Configuracoes`.
3. Va ate `Seguranca de Dados`.
4. Clique em `Baixar Backup`.
5. Guarde o arquivo `.json` em local seguro.

## Como restaurar backup

1. Abra `Configuracoes`.
2. Va ate `Seguranca de Dados`.
3. Clique em `Restaurar Dados`.
4. Selecione o arquivo `.json`.
5. Confirme apenas se tiver certeza.

Ao restaurar, os dados atuais sao substituidos pelos dados do arquivo.

## Cuidados

- Nao compartilhe backups publicamente.
- Nao envie backups por issues do GitHub.
- Mantenha copia em mais de um lugar seguro.
- Confirme se o arquivo pertence ao mesmo negocio antes de restaurar.

## Dados incluidos

O backup inclui:

- Perfil local.
- Configuracoes.
- Atendimentos.
- Vales e retiradas.
- Produtos e barbeiros cadastrados.

## Limitacoes

- O backup nao sincroniza automaticamente entre dispositivos.
- A restauracao depende de arquivo local.
- Dados ficam sob responsabilidade do usuario.
